Surface figure assets (CC0 MakeHuman lineage)

- makehuman-body.glb — Converted from MakeHuman Community CC0 base.obj
  (makehumancommunity/makehuman). Exact MakeHuman 1.2/1.3 modifier export from
  body-explorer-spec.md could not be run in this VM (no MakeHuman GUI/CLI).
  Base mesh is scaled to ~1.72 m, feet on ground, Y-up, face +Z, left=+X.
- makehuman-hair.glb — short04 hair OBJ from MakeHuman 1.2 assets (CC0),
  aligned to the same body transform; procedural dark hair texture with
  alphaMode MASK.
- makehuman-shorts.glb — procedural shorts fitted to the body hips; mesh node
  named Cloth_shorts (viewer recolors Cloth_* meshes).

Landmark table from the original MakeHuman export is used as specified; if a
highlight lands off-target on this base mesh, nudge that landmark.
